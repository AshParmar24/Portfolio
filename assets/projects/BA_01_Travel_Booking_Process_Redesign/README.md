# Enquiry to Booking Process Redesign

Requirements and process analysis for Wren & Harbour Travel, a fictional independent travel agency. The enquiry log is synthetic and reproducible.

## What is in this folder
| File | Purpose |
|---|---|
| `Wren_Harbour_Requirements_Workbook.xlsx` | Enquiry log, formula-driven baseline KPIs, stakeholders and RACI, requirements, user stories, gap analysis, data dictionary, traceability |
| `process_map_as_is.svg` | Swimlane map of the current process with six pain points |
| `process_map_to_be.svg` | Swimlane map of the proposed process |
| `enquiry_log.csv` | Eight weeks of enquiries (596 rows) |
| `ba01_generate_enquiries.py` | Seeded generator for the enquiry log |

## Baseline
- 5 percent of written enquiries answered within two hours.
- 57 percent of quotes followed up.
- 10 percent of bookings need a correction.
- Conversion: 32 percent for phone and walk-in, 15 percent for written enquiries.

## Deliverables
19 requirements (MoSCoW), 9 user stories with acceptance criteria, as-is and to-be process maps, stakeholder map and RACI, data dictionary with personal data marked, objectives traced to requirements and measures.
