About this project. PayFlow Global is a fictional payroll platform and its client base is synthetic. The legislation is real: the rates, thresholds and rounding rule are taken from HMRC guidance and every expected test result is checked against an independent calculation.

Payroll Statutory Change: Employer National Insurance

Scenario. The Autumn Budget 2024 changed employer National Insurance from 6 April 2025: the rate rose from 13.8 to 15 percent, the secondary threshold fell from £9,100 to £5,000 a year, and the Employment Allowance rose from £5,000 to £10,500 with the £100,000 eligibility limit removed. PayFlow, a cloud payroll platform with 1,150 UK employer clients, had to change its calculation engine, claim screen, reports and client communications before the first April pay run.

My role. Business systems analyst. I read the legislation, turned it into business rules with worked examples, wrote the requirements and user stories, designed the acceptance tests with calculated expected results, and traced every legislative change through to a test.

Impact analysis

An employee on £30,000 costs the employer £865.80 more a year in National Insurance (£2,884.20 to £3,750.00). The increase is £615 at the old threshold and grows by £12 for every extra £1,000 of salary, so the percentage rise is largest for lower-paid and part-time staff.

Employer NIC per employee by annual salary (£)
Clients paying less or the same after the change, by size (%)

The larger Employment Allowance changes who is affected. In the modelled client base, 326 of 1,150 clients (28 percent) pay less or the same after the change: every employer with one to four staff, and 102 of 254 with five to nine. Everyone with ten or more employees pays more. That shaped two requirements: a cost comparison report (FR-08) and a client notice that states each client's own estimated impact (FR-09), because a single generic message would be wrong for more than a quarter of clients.

A defect the analysis caught before development

Test TC-11 pays £3,150.50. The calculation gives exactly £410.025. A spreadsheet ROUND function returns £410.03. The legislation says an exact half penny is rounded down, so the correct answer is £410.02. I wrote this in as business rule BR-07, built the expected results with a half-down formula, and added the case to the regression pack.

Independent reference calculation

nic_reference_calculator.py
"""
Employer (secondary) Class 1 National Insurance: reference calculator
---------------------------------------------------------------------
An independent calculation used to check the expected results in the UAT pack.
Scope: monthly-paid employees, category letters A, M (under 21) and H (apprentice under 25).
Out of scope: directors' annual earnings method, other category letters, Class 1A and 1B.

Parameters are selected by PAYMENT DATE, not by the period the work was done in.
Rounding follows the statutory rule: nearest penny, with an exact half penny rounded down.
"""
from datetime import date
from decimal import Decimal, ROUND_HALF_DOWN

PARAMS = {
    # tax year: rate, monthly secondary threshold, monthly upper secondary threshold, employment allowance
    "2024-25": {"from": date(2024, 4, 6), "to": date(2025, 4, 5), "rate": 0.138, "st_month": 758, "ust_month": 4189, "allowance": 5000},
    "2025-26": {"from": date(2025, 4, 6), "to": date(2026, 4, 5), "rate": 0.15,  "st_month": 417, "ust_month": 4189, "allowance": 10500},
}

def params_for(payment_date: date) -> dict:
    for p in PARAMS.values():
        if p["from"] <= payment_date <= p["to"]:
            return p
    raise ValueError(f"No parameter set covers {payment_date}")

def employer_nic(gross_month: float, category: str, payment_date: date) -> float:
    p = params_for(payment_date)
    # M and H: nothing is due until earnings pass the upper secondary threshold
    threshold = p["ust_month"] if category in ("M", "H") else p["st_month"]
    due = max(Decimal(0), Decimal(str(gross_month)) - threshold) * Decimal(str(p["rate"]))
    # Regulation 12(1)(b), Social Security (Contributions) Regulations 2001:
    # round to the nearest penny, and an exact half penny is rounded DOWN.
    return float(due.quantize(Decimal("0.01"), rounding=ROUND_HALF_DOWN))

def allowance_used(monthly_liability: float, months: int, payment_date: date) -> float:
    """Employment Allowance offset against liability so far this tax year."""
    return round(min(params_for(payment_date)["allowance"], monthly_liability * months), 2)

if __name__ == "__main__":
    for gross in (400, 417, 418, 758, 1500, 2500, 4189, 6000):
        old = employer_nic(gross, "A", date(2025, 3, 28))
        new = employer_nic(gross, "A", date(2025, 4, 28))
        print(f"gross £{gross:>6,.2f}  2024-25 £{old:>7.2f}  2025-26 £{new:>7.2f}  change £{new - old:>7.2f}")
